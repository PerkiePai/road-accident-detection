# Plan: Auto-Calibration Using Lane Width

## Context

The pipeline requires `H_manual.npy`, `src_manual.npy`, and `track_manual.npy` generated by clicking 4 road corners manually in `manual_calibrate.py`. This must be repeated for each camera view. Since Thai road lanes are a known standard (**3.5 m/lane**), we can detect lane lines automatically with Hough transform, count lanes, and derive the homography without full manual clicking.

**Interaction level chosen:** Semi-automatic — auto-detect 4 road corners, then open a drag-to-confirm OpenCV window before saving.

---

## New file: `auto_calibrate.py`

Saves the same three `.npy` files so `detect.py` works unchanged.

### Constants

```python
LANE_WIDTH_M = 3.5   # one lane, Thai standard
ROAD_DEPTH_M = 30.0  # longitudinal depth; adjust to match actual visible road distance
```

---

### `AutoCalibrator` class

#### `detect_lane_lines(frame)` → `(left_line, right_line, mid_lines)`

| Step | Action |
|------|--------|
| 1 | Grayscale → Gaussian blur (5×5) |
| 2 | Canny(50, 150) |
| 3 | Trapezoid ROI mask — lower ~65% of frame |
| 4 | `HoughLinesP(rho=1, theta=π/180, threshold=50, minLineLength=100, maxLineGap=50)` |
| 5 | Filter: keep only `|slope| > 0.3` (remove near-horizontal lines) |
| 6 | Separate: `slope < 0` → left candidates, `slope > 0` → right candidates |
| 7 | Fit each group to one line via length-weighted average of endpoints |
| 8 | Return left boundary, right boundary, and intermediate lines |

#### `count_lanes(left_line, right_line, mid_lines)` → `int`

- For each intermediate segment, compute x-midpoint at a reference y
- 1-D cluster midpoints between the two boundaries (gap > 30 px = new cluster)
- `num_lanes = num_clusters + 1`
- Fallback: `num_lanes = 2` if no intermediate lines found

#### `find_corners(left_line, right_line, y_bottom, y_top)` → `np.float32 (4,2)`

Intersect each boundary line at two y-levels:

```
bl = left_line  ∩ y_bottom    (y_bottom = 85% of frame height)
br = right_line ∩ y_bottom
tr = right_line ∩ y_top       (y_top    = 45% of frame height)
tl = left_line  ∩ y_top
```

Returns `[bl, br, tr, tl]` — same order as `ManualCalibrator`.

#### `confirm_corners(frame, corners)` → `np.float32 (4,2)`

Interactive OpenCV window:

- 4 draggable coloured circles labelled `bl / br / tr / tl`
- Semi-transparent filled quad shows calibration region
- `r` → re-run lane detection and reset corners
- `Enter` → accept
- `q` → cancel (raises `RuntimeError`)

#### `compute_homography(src_pts, num_lanes)` → `H`

```python
lane_width_m = num_lanes * LANE_WIDTH_M
dst = np.float32([
    [0,             ROAD_DEPTH_M],   # bl
    [lane_width_m,  ROAD_DEPTH_M],   # br
    [lane_width_m,  0           ],   # tr
    [0,             0           ],   # tl
])
H, _ = cv2.findHomography(src_pts, dst)
```

#### `calibrate(cap, save_path="H_manual.npy", frame_idx=0)`

1. Read frame at `frame_idx`
2. `detect_lane_lines(frame)` → boundaries + mid-lines
3. `count_lanes(...)` → print detected lane count
4. `find_corners(...)` → initial corner estimates
5. `confirm_corners(frame, corners)` → user-confirmed corners
6. `compute_homography(corners, num_lanes)` → H
7. Reuse `ManualCalibrator._pick_tracking_polygon()` for tracking region (Phase 2)
8. Save `H_manual.npy`, `src_manual.npy`, `track_manual.npy`
9. Write `calib_debug_auto.png` (frame with detected corners overlaid)
